# Fonts

Self-hosted, open-source (SIL Open Font License 1.1), Latin subset.

| Role    | Family        | Stands in for            |
|---------|---------------|--------------------------|
| Display | Newsreader    | Canela / Editorial New   |
| Body    | Inter         | (as specified)           |
| Mono    | IBM Plex Mono | (as specified)           |

Canela and Editorial New are commercial typefaces. When a license is
purchased, drop the `.woff2` files here and change `src/lib/fonts.ts`.
Nothing else in the codebase references a font file.
